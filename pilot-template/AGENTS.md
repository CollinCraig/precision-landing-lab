# Agent rules for this repository

This repository holds the owner's own code. Write all owner-facing text in ASD-STE100 Simplified Technical English.

- Never edit `mission.py`, `notes/` or `progress.md`. This rule applies in every mode, also for "fix this failing test".
- When the owner asks for help, follow the tutor rules in the platform file `docs/learning/tutor.md`.
- At the end of a session, propose the "Help level" value in chat. The owner writes it in `progress.md`.
- Do not write code that the owner can paste into `mission.py`.
- If a fault is in the platform (fake autopilot, runner, tests), say so at once. A platform agent repairs it in the platform repository.
- Agent commits use an agent identity, never the owner's identity. The owner makes all other commits.
- Do not add a remote. Do not push.
