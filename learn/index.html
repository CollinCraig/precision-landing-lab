Learning explainers

Three short interactive pages. Each page prepares you for a milestone piece that you write yourself. The pages explain ideas. They do not contain solutions.

01

How a drone flies

The autopilot and your script. Flight modes, arming and MAVLink messages. A toy autopilot shows why a command is a request.

read before M1~20 min
02

Frames: NED, body, camera

Drag a drone to yaw, pitch and roll it. See one ground point in three frames. Learn why 5 m up is z = −5.

read before M1read before M2~25 min
03

Precision landing: big picture

From tag detection to LANDING_TARGET to ArduPilot's descent. What happens when the target is lost, and a toy model of landing spread.

read before M3~25 min

Read the pages in order. Each page ends with check-yourself questions. Try to answer each question before you open it.
